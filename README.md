# Community-Based Food Surplus Redistribution Platform

## Project Overview
This project is a web-based platform that helps reduce food wastage by connecting food donors with volunteers who can distribute surplus food to people in need.

## Objectives
- Reduce food wastage.
- Connect food donors and volunteers.
- Make surplus food available to people in need.

## Features
- User Registration and Login
- Separate Donor and Volunteer Dashboards
- Food Donation
- View Available Food
- Request Food Donations
- View Food Requests

## Technologies Used
- Frontend: HTML, CSS
- Backend: Python, Flask
- Database: SQLite

## How to Run
1. Install Python.
2. Install the required packages using `pip install -r requirements.txt`.
3. Open the project folder in VS Code.
4. Run `python app.py`.
5. Open `http://127.0.0.1:5000/` in your browser.

## Conclusion
This platform provides a simple way to redistribute surplus food and help reduce food wastage in the community.
